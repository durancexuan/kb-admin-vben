# 加油站知识库 · 机器人检索接口（负责人对接版）

> 版本：与仓库 `main` 分支 kb-api 一致  
> 接口类型：**HTTP JSON API**（不是网页链接，需在程序里调用）  
> 提供方配置好服务后，将 **Base URL** 与 **Api Key** 一并发给你。

---

## 一、接口概览

| 项目 | 说明 |
| --- | --- |
| 功能 | 根据用户一句话，从「问答 / 商品 / 活动」三库中选出**一条**最适合的播报内容 |
| 方法 | `POST` |
| 路径 | `/api/robot/knowledge/query` |
| 完整地址 | `{BaseURL}/api/robot/knowledge/query`（示例：`http://47.1.2.3:8080/api/robot/knowledge/query`） |
| 鉴权 | 请求头 `X-Robot-Api-Key: <由提供方分配的密钥>` |
| 编码 | `Content-Type: application/json; charset=utf-8` |

**健康检查（可选）**：`GET {BaseURL}/health` → 返回 `{"ok":true}` 表示服务在线。

---

## 二、请求

### 2.1 请求头

| Header            | 必填 | 值                             |
| ----------------- | ---- | ------------------------------ |
| `Content-Type`    | 是   | `application/json`             |
| `X-Robot-Api-Key` | 是   | 提供方分配的密钥，错误返回 401 |

### 2.2 请求体（JSON）

```json
{
  "utterance": "卫生间在哪里"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `utterance` | string | **是** | 用户原话（语音识别文本），不能为空 |
| `hints.category` | string | 否 | 仅缩小**问答库**范围：`加油机` / `卫生间` / `便利店` / `营业时间` / `其他` |
| `stationId` | string | 否 | 油站 ID，默认 `default`，一般可不传 |

### 2.3 请求示例

```http
POST /api/robot/knowledge/query HTTP/1.1
Host: 47.1.2.3:8080
Content-Type: application/json
X-Robot-Api-Key: your-secret-key-here

{"utterance":"卫生间在哪里"}
```

## 三、响应

### 3.1 外层结构

```json
{
  "code": 0,
  "message": "ok",
  "error": null,
  "data": {}
}
```

| `code` | 含义                                    |
| ------ | --------------------------------------- |
| `0`    | 请求成功（是否命中知识库看 `data.hit`） |
| 非 `0` | 业务/系统错误（少见）                   |

HTTP 状态码：`200` 为正常；`401` 密钥错误；`400` 请求体不合法。

### 3.2 `data` 字段（对接核心）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `utterance` | string | 回显用户原话 |
| **`hit`** | boolean | **`true` = 可以播报**；`false` = 不要播报，勿读 `speak` |
| `library` | string \| null | 命中来源：`qa` 问答 / `goods` 商品 / `campaign` 活动 |
| `libraryLabel` | string \| null | 中文：`站级问答库` / `商品全维库` / `营销活动库` |
| **`confidence`** | number \| null | **综合置信度** 0~1，用于判断是否命中（服务端阈值默认 0.35） |
| `vectorConfidence` | number \| null | **向量语义相似度** 0~1；仅问答/商品走向量或混合检索时有值，可作展示 |
| `matchType` | string \| null | 匹配方式，见下表 |
| `display` | string \| null | 短标题（问题/商品名/活动名），可供屏幕展示 |
| **`speak`** | string \| null | **TTS 播报正文**，`hit=true` 时读这段 |

### 3.3 `matchType` 说明

| 值        | 含义                                      |
| --------- | ----------------------------------------- |
| `keyword` | 关键词匹配                                |
| `vector`  | 向量语义检索                              |
| `hybrid`  | 关键词 + 向量混合                         |
| `exact`   | 商品 SKU 精确匹配                         |
| `intent`  | 固定话术汇总（如「近期有什么活动/商品」） |

### 3.4 对接逻辑（伪代码）

```
response = POST 知识库接口(utterance)

if response.data.hit == true:
    播放 TTS(response.data.speak)
else:
    走兜底话术（如「抱歉，暂未查到相关信息」）
```

**注意：**

- 门控请用 **`hit`**，不要仅用 `vectorConfidence`。
- `confidence` 为综合分；`vectorConfidence` 仅表示语义相似强度，可能为 `null`。

## 五、推荐测试话术

| 用户说法 | 预期 `library` | 说明 |
| --- | --- | --- |
| 卫生间在哪里 | `qa` | 站级问答 |
| 矿泉水 / 有没有喝的 | `goods` | 单品检索 |
| 近期有什么活动 / 最近有没有活动 | `campaign` | 活动汇总，最多 3 条，按开始时间由晚到早 |
| 近期有什么商品 | `goods` | 类目聚合 + SKU 编号靠后 3 款 |
| SKU-0005 | `goods` | SKU 精确匹配 |

## 六、联调方式

### 6.1 curl（Linux / Mac）

```bash
curl -s -X POST "http://<BaseURL主机>:8080/api/robot/knowledge/query" \
  -H "Content-Type: application/json" \
  -H "X-Robot-Api-Key: <密钥>" \
  -d '{"utterance":"卫生间在哪里"}'
```

### 6.2 Postman / Apifox

1. 方法：`POST`
2. URL：`http://<IP>:8080/api/robot/knowledge/query`
3. Headers：`Content-Type: application/json`，`X-Robot-Api-Key: <密钥>`
4. Body → raw → JSON：`{"utterance":"卫生间在哪里"}`

**浏览器地址栏无法直接测试本接口**（需要 POST + 自定义 Header）。

### 6.3 Java（OkHttp 示例）

```java
OkHttpClient client = new OkHttpClient();
String json = "{\"utterance\":\"卫生间在哪里\"}";
Request request = new Request.Builder()
    .url("http://<IP>:8080/api/robot/knowledge/query")
    .post(RequestBody.create(json, MediaType.parse("application/json")))
    .addHeader("X-Robot-Api-Key", "<密钥>")
    .build();
Response response = client.newCall(request).execute();
// 解析 JSON，若 data.hit==true 则 TTS 播放 data.speak
```

### 6.4 Python（requests 示例）

```python
import requests

r = requests.post(
    "http://<IP>:8080/api/robot/knowledge/query",
    headers={
        "Content-Type": "application/json",
        "X-Robot-Api-Key": "<密钥>",
    },
    json={"utterance": "卫生间在哪里"},
    timeout=10,
)
data = r.json()["data"]
if data["hit"]:
    play_tts(data["speak"])
```

## 七、错误与排查

| 现象                | 可能原因                                     |
| ------------------- | -------------------------------------------- |
| HTTP 401            | `X-Robot-Api-Key` 错误或缺失                 |
| HTTP 400            | 未传 `utterance` 或 JSON 格式错误            |
| 连接超时 / 拒绝连接 | 服务未启动、IP/端口错误、防火墙/安全组未放行 |
| 始终 `hit: false`   | 知识库无相关已上线数据，或置信度低于阈值     |
| 返回 HTML 而非 JSON | 地址打错（打到前端页面而非 kb-api）          |

## 九、附录：后台识别规则（了解即可）

```
用户 utterance
  → 若为「活动类」汇总问法 → 仅查活动库，播报最多 3 条（按活动开始时间由晚到早）
  → 若为「在售商品类」汇总问法 → 仅查商品库，按类目聚合 + SKU 靠后 3 款
  → 否则并行查问答、商品、活动各 1 条 → 取 confidence 最高者
  → confidence ≥ 0.35 → hit = true
```

技术细节见仓库内 `apps/kb-api/ROBOT_API.zh-CN.md`。
