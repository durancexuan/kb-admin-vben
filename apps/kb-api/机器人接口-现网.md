# 加油站知识库 · 机器人检索接口（现网）

> 部署环境：内网服务器 `192.168.13.7`  
> 接口类型：**HTTP JSON API**（需在程序里 `POST` 调用，不能浏览器直接打开路径）

---

## 一、对接信息

| 项目             | 值                                                        |
| ---------------- | --------------------------------------------------------- |
| **Base URL**     | `http://192.168.13.7:8089`                                |
| **完整接口**     | `POST http://192.168.13.7:8089/api/robot/knowledge/query` |
| **Api Key**      | `abba8fd282de1bd03366be58664a033a`                        |
| **Content-Type** | `application/json`                                        |

**健康检查**：`GET http://192.168.13.7:8089/health` → `{"ok":true,...}` 表示服务在线。

---

## 二、请求说明

### 2.1 请求头

| Header            | 必填 | 值                                 |
| ----------------- | ---- | ---------------------------------- |
| `Content-Type`    | 是   | `application/json`                 |
| `X-Robot-Api-Key` | 是   | `abba8fd282de1bd03366be58664a033a` |

密钥错误时返回：`{"message":"Invalid robot api key"}`（HTTP 401）。

### 2.2 请求体

```json
{
  "utterance": "卫生间在哪里"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `utterance` | string | **是** | 用户原话（语音识别文本），不能为空 |
| `hints.category` | string | 否 | 仅缩小**问答库**范围：`加油机` / `卫生间` / `便利店` / `营业时间` / `其他` |
| `stationId` | string | 否 | 油站 ID，默认 `default`，一般可不传 |

### 2.3 HTTP 原始请求示例

```http
POST /api/robot/knowledge/query HTTP/1.1
Host: 192.168.13.7:8089
Content-Type: application/json
X-Robot-Api-Key: abba8fd282de1bd03366be58664a033a

{"utterance":"卫生间在哪里"}
```

## 三、响应说明

### 3.1 外层结构

```json
{
  "code": 0,
  "message": "ok",
  "error": null,
  "data": {}
}
```

| `code` | 含义                              |
| ------ | --------------------------------- |
| `0`    | 请求成功（是否播报看 `data.hit`） |
| 非 `0` | 业务/鉴权错误                     |

### 3.2 对接时重点看的字段

| 字段 | 说明 |
| --- | --- |
| **`data.hit`** | `true` = 可以播报；`false` = 无合适答案，勿读 `speak` |
| **`data.speak`** | **机器人播报话术**（对接核心） |
| `data.library` | 命中来源：`qa` 问答 / `goods` 商品 / `campaign` 活动 |
| `data.confidence` | 综合置信度 0~1，用于判断是否采纳 |
| `data.vectorConfidence` | 向量相似度（问答/商品可能有值） |
| `data.matchType` | `keyword` / `vector` / `hybrid` / `intent` 等 |

### 3.3 成功命中示例（问答）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "utterance": "卫生间在哪里",
    "hit": true,
    "library": "qa",
    "libraryLabel": "站级问答库",
    "confidence": 0.6881,
    "vectorConfidence": 0.5201,
    "matchType": "hybrid",
    "display": "卫生间在哪里？",
    "speak": "进入便利店后左转即到，设有无障碍卫生间。"
  }
}
```

## 四、本机测试（Windows）

项目根目录已提供测试 JSON：`test-robot-query.json`，修改其中 `utterance` 即可换问题。

**推荐**（用 JSON 文件，避免 PowerShell 转义问题）：

```bash
curl.exe -s -X POST "http://192.168.13.7:8089/api/robot/knowledge/query" ^
  -H "Content-Type: application/json" ^
  -H "X-Robot-Api-Key: abba8fd282de1bd03366be58664a033a" ^
  -d "@e:\kb-admin-vben-tmp\test-robot-query.json"
```

### 常用测试话术

| 用户说法                            | 预期                  |
| ----------------------------------- | --------------------- |
| `卫生间在哪里`                      | 问答库                |
| `最近有没有活动` / `近期有什么活动` | 活动汇总              |
| `近期有什么商品`                    | 商品在售汇总          |
| `有没有吃的`                        | 商品库（语义/关键词） |

## 五、与本地开发的区别

| 环境 | 地址 | Api Key |
| --- | --- | --- |
| **现网（服务器）** | `http://192.168.13.7:8089` | `abba8fd282de1bd03366be58664a033a` |
| 本地开发 | `http://127.0.0.1:8080` | `robot-dev-key`（`.env` 默认） |

README 里 `robot-dev-key` 的 curl 示例**仅适用于本机**；对接服务器请用本文密钥。
